# Diplom_Online-Shop

# 👕 Интернет-магазин мужской одежды (NiStore)

## 📌 О проекте

**NiStore** — это полнофункциональный интернет-магазин мужской одежды, разработанный в рамках дипломного проекта.  
Система предоставляет пользователям удобный каталог товаров, корзину, авторизацию и возможность оформления заказов.

Проект выполнен с использованием современного технологического стека:
- **Frontend**: React.js, Material-UI, Axios
- **Backend**: Node.js, Express.js, JWT
- **Database**: PostgreSQL, Sequelize ORM

---

## 🚀 Основной функционал

### Для покупателей:
- Регистрация и авторизация (JWT)
- Просмотр каталога товаров (обычные и популярные)
- Фильтрация по цветам и категориям (в разработке)
- Добавление товаров в корзину
- Управление корзиной (изменение количества, удаление товаров)
- Оформление заказа
- Плавная навигация по странице

### Для администраторов (планируется в v2.0):
- Управление товарами (CRUD)
- Управление заказами
- Просмотр статистики
